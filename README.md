# Hana Abdikadir

Front-end developer. Portfolio site with selected work, skills, and contact.

**Live:** [hana-abdikadir-portfolio.netlify.app](https://hana-abdikadir-portfolio.netlify.app)

## Run locally

```bash

npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
